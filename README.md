## 🔥 Featured Project — Fluxy Framework

**Fluxy** is a declarative reactive UI framework for Flutter inspired by **SwiftUI, TailwindCSS, and Expo**.

### Why Fluxy?
- ⚡ Ultra-clean UI syntax
- 🔁 Reactive signals & atomic state
- 🎯 Layout + animation DSL
- 🧠 Built-in routing & navigation
- 🛠 CLI for instant project setup

🌐 Docs: https://fluxy-doc.vercel.app  
📦 pub.dev: https://pub.dev/packages/fluxy  
💻 GitHub: https://github.com/swaingithub/fluxy
